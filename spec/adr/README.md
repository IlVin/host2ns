# ADR — host2ns

| Номер | Решение | Статус |
| --- | --- | --- |
| ADR-0001 | Делегирование подзоны своему NSD вместо API регистратора | принято |
| ADR-0002 | Push по SSH вместо внешнего DDNS-провайдера | принято |
| ADR-0003 | Установка без интерактивного sudo (NOPASSWD на один установщик) | принято |
| ADR-0004 | Зоны — производное конфига, а не рантайм-регистрация | принято |
| ADR-0005 | Семейство адресов выбирается, а не угадывается | принято |
| ADR-0006 | NSD слушает конкретные адреса, systemd-resolved остаётся | принято |
| ADR-0007 | Бутстрап NSD — транзакционный takeover, а не безусловный restart | принято |
| ADR-0008 | Не дублировать адреса и зоны старой конфигурации | принято |
| ADR-0009 | NSD — лёгкий сервер для дешёвого VPS | принято |
| ADR-0010 | Зоны — у своего NS, а не в UI/API провайдера | принято |
