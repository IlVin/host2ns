# spec — спецификации host2ns

| Файл | Отвечает на вопрос |
| --- | --- |
| `problem.md` | зачем это нужно, при каких ограничениях |
| `architecture.md` | из чего состоит и как течёт поток |
| `zones.md` | модель имён и формат зоны |
| `install.md` | что делает установщик и почему идемпотентен |
| `bootstrap-nsd.md` | как ставится NSD и почему так |
| `pitfalls.md` | грабли и их причины |
| `testing.md` | чем подтверждается работа |
| `adr/` | принятые решения и отвергнутые варианты |

Порядок чтения для нового человека: `problem` → `architecture` → `zones` →
`install` → `testing`. Остальное — по мере необходимости.
