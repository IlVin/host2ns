# AGENTS.md — правила работы над host2ns

Короткая версия правил основного проекта: здесь только то, что важно для этого
репозитория.

## 1. Артефакты

Problem — `spec/problem.md`; Spec — остальные файлы `spec/`; ADR —
`spec/adr/`; Code — `scripts/`; Test — `scripts/check.sh` и `make status`.

Порядок: Problem → (Spike → ADR) → Spec → Code → Test.

## 2. Что нельзя

- править зоны на NS-хосте руками: они производное от состояния;
- менять юниты без правки `spec/bootstrap-nsd.md` и `spec/install.md`;
- добавлять второй экземпляр логики: генерация зон живёт только в `zonegen.sh`;
- считать работу сделанной без `make check` и `make status`.

## 3. Стиль

Документация и комментарии — по-русски, заголовки коммитов — по-английски.
У каждого каталога есть README с объяснением для человека.
